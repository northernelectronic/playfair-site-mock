# Playfair Fun & Games — mock marketing site

This is a **mock** public page for Playfair Fun & Games (“You’re Invited to Play”). It is not a live shop, does not accept payment, and the contact form does not send anywhere.

The page is set to `noindex, nofollow`. It is a review demo only. No custom domain has been registered.
